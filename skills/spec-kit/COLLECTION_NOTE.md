# Spec Kit（本合集内的副本）

上游仓库：[github/spec-kit](https://github.com/github/spec-kit)

这不是单个 SKILL.md，而是 **Spec-Driven Development** 工具包（含 specify CLI、各类 agent 集成与文档模板）。

## 推荐用法

更推荐直接按上游官方安装（保持可升级），例如：

```bash
uv tool install specify-cli --from git+https://github.com/github/spec-kit.git@vX.Y.Z
```

详见本目录 README.md（上游原文）。

本目录为整理备份，便于离线查阅模板与流程；正式项目请优先跟随上游 Release 安装。
